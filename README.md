# Chest Counter

## 1. Host the lobby server (one person, once)
Easiest free route: upload this folder to GitHub, then create a free "Web Service" on Render.com (Build: `npm install`, Start: `npm start`).
Or run locally: `npm install && npm start`, then open http://localhost:3000 (friends on the same Wi-Fi use your PC's IP).

## 2. Everyone installs it
- Android: open the server URL in Chrome > menu > "Install app". It gets its own icon and runs like an app.
- PC: open the URL in Chrome/Edge > install icon in the address bar.
- Real APK: go to pwabuilder.com, paste your server URL, pick Android, download the APK/AAB.

## 3. Play
One person taps "New" for a lobby code; friends type it and tap Join.
